# Agent guide — how these videos are made, end to end

Written for the next agent. Everything here was executed at least once; the pitfalls section records real failures and their fixes. Complementary docs: `AGENTS.md` (rules), `README.md` (repo map), `VIDEO_STYLE.md` (taste), `docs/references/` (distilled vendor knowledge).

## 0. One-time setup

```bash
npm ci                          # pinned deps: hyperframes, gsap, fonts, ffmpeg/ffprobe-static
npm run hf -- browser ensure    # installs chrome-headless-shell into .cache/hyperframes
npm run hf -- doctor            # optional: reports missing system libraries
```

- Use Node ≥ 22 (24 tested). The wrapper `scripts/hf.mjs` pins FFmpeg/FFprobe from `ffmpeg-static`/`ffprobe-static`, disables telemetry and redirects render temp to `.cache/hyperframes-tmp`.
- On minimal Linux, headless Chrome may need NSS/ALSA/ATK/CUPS/GBM/X11 system libraries; `doctor` lists them.
- Software GL (llvmpipe/SwiftShader) is fine — rendering is screenshot-based. Keep `--workers 1` on small machines (~2 GB RAM): one worker rendered 720 frames in ~60 s and 1560 frames in ~2.5 min.

## 1. Anatomy of a film

```text
revisions/<id>/
  film.config.json      ← single source of truth (sizes, duration, narration, QA points)
  src/film.html         ← sparse DOM; every element the timeline touches has an id
  src/film.css          ← look + *initial hidden states* (opacity:0 etc.), no initial transforms
  src/film.js           ← ONE paused GSAP timeline → window.__timelines[<compositionId>]
  icons.mjs             ← optional: extra SVG icons (default export = path dict)
  audio/narration-N.mp3 ← measured narration chunks
  index.motion.json     ← motion intent assertions for `check`
  composition/          ← GENERATED by build-film.mjs. Never edit.
  qa/                   ← lint/check/test reports, keyframes, contact sheet
```

The build (`scripts/build-film.mjs`) inlines: local Inter variable fonts (base64 `@font-face`), local GSAP + MotionPathPlugin bundles (sourcemap comments stripped), `{{icon:name}}` placeholders resolved through `revisions/<id>/icons.mjs` (falls back to `src/icons.mjs` **with a loud console warning**), `<audio>` tags from `config.narration`, plus `hyperframes.json` / `index.motion.json` metadata. Output is a single self-contained `index.html` (~190 KB) + `assets/` — no CDN, no studio, no network at runtime.

## 2. Timeline rules (seek-safety contract)

The renderer seeks the timeline to arbitrary times; Hyperframes `check` samples 300 motion points, including backwards and non-sequential seeks. Therefore:

1. `const TL = gsap.timeline({ paused: true })`, registered as `window.__timelines['<compositionId>']`. Never play it in the composition.
2. No wall clock, no randomness, no network, no user input. One deterministic value per time.
3. Drive one camera object via one `applyCamera()` function; every camera tween sets `onUpdate: applyCamera`. Camera = `translate(…px, …px) scale(z)` on `#world`.
4. Entrance tweens are **`fromTo`** with the hidden state in the `from` (and `opacity:0` also declared in CSS for exact frame zero). Never combine a CSS `transform` with GSAP transform tweens — lint error `gsap_css_transform_conflict`, and a real rendering hazard.
5. Normalized SVG strokes (`pathLength="1"`, `stroke-dasharray:1; stroke-dashoffset:1` in CSS) reveal with `strokeDashoffset: 0, autoRound: false`. **Without `autoRound:false`, GSAP pixel-rounds the dash offset and the draw snaps** — this shipped a visible graph glitch in 002 before being caught by mid-time screenshots.
6. A leading dot on a drawn path must use MotionPathPlugin on the *same* path with the *same* progress; QA compares `getPointAtLength(L*p)` to the dot's screen position.
7. Element swaps between two DOM nodes (e.g. graph end → result badge) must be continuous: same world position at the switch frame, tested with a <0.2 px jump assertion (see `scripts/qa-motion-002.mjs`).
8. Kill stale content: retiring panels fade/rise/shrink *before or while* the camera leaves. Overlapping stale scenes were a real review finding in 003 — titles and connectors must retire too, not just cards.

### Frame zero

The first rendered frame must already contain the subject (`frameZero` config selectors assert it). Declare initial hidden states in CSS; set initial geometry with an immediate `gsap.set(...)` (or `fromTo` immediateRender) before the first paint. Lint used to warn `gsap_timeline_set_initial_hide` for initial states authored as timeline `set(...,0)` tweens — that's why CSS owns the hidden state.

## 3. Narration workflow

Voice is synthetic, generated at authoring time, committed as MP3 under `revisions/<id>/audio/`. Owner's narration preferences (since 005): **longer sentences, short gaps (≈0.38 s), faster delivery** — generate at natural pace, then `atempo≈1.12`, and measure everything.

1. Write the script per scene; generate clips; save as `audio/narration-N.mp3`.
2. Measure each clip: `ffprobe -v error -show_entries format=duration -of csv=p=0 file`.
3. Put `{file, start, duration, track}` into `film.config.json`. Choose scene boundaries around the speech: entrances land *with* the sentence that introduces them; leave ≥0.3 s of quiet before camera pans.
4. Build; the config becomes `<audio id="narration-N" data-start="…" data-duration="…" data-track-index="2" src="assets/audio/narration-N.mp3">`.
5. Run the Hyperframes check: its runtime step re-measures media and **flags any slot longer than the real audio** (`clip_media_fit`). Trust its number over `ffprobe`'s (MP3 encoder padding makes them differ slightly) and fix the config.
6. `npm test` asserts the rendered DOM carries exactly the planned starts/durations.

Traps (all hit once):
- **Missing `id` on `<audio>`** → lint error `media_missing_id`; “the renderer requires id to discover media elements — this audio will be SILENT in renders”.
- Slot `data-duration` > real length → warning and truncated audio.
- Total speech ~45.5 s → film 52 s: keep breathing room; the closing scene needs its own hold.

## 4. Portrait vs landscape

Purely config: `width`, `height` (and the world math in `film.js`). The 003 pattern generalizes to any format:

- World is a large fixed surface (e.g. 2400×2100).
- Define N viewports of canvas size; the camera moves between their centers.
- Portrait 1080×1920 viewports sit side by side horizontally (x = 540, 1860); landscape ones can sit diagonally to allow more travel.
- Compose per viewport: title top, focus element upper-center, supporting nodes below, summary low. Vertical real estate favors vertical flows (app → server → data worked well).

## 5. QA ladder

Run in order; do not skip to render.

1. **Lint** — `node scripts/hf.mjs lint revisions/<id>/composition --json`. Must be 0/0. It catches: missing audio ids, CSS/GSAP transform conflicts, initial-hide-in-timeline, unmotivated elements.
2. **Browser tests** — `node scripts/test-film.mjs --rev <id>`: opens the built composition from `file://` in headless Chrome (viewport = film size, deviceScaleFactor 0.5 for speed) and asserts: no external requests, no interactive UI (`button,input,iframe,nav`), brand-scan words absent, frame-zero content present, narration wiring, **deterministic signatures across forward/backward/non-sequential seeks** (computed styles + transforms of `signatureIds`), then writes screenshots + contact sheet per `config.screenshots`.
   - Implementation note: the seek helper must **not return the GSAP timeline** from `page.evaluate` — timelines are thenable and Puppeteer will await them forever (this hung a test run until timeout). Return nothing.
3. **Revision-specific deep QA** — geometry you care about: stroke/tip alignment, constant style during reveals, handoff continuity, panel retirement (`scripts/qa-motion-002.mjs` is the reference implementation).
4. **Hyperframes check** — `node scripts/hf.mjs check revisions/<id>/composition --at <times> --json > qa/hyperframes-check.json`. Include mid-transition times (pans, swaps), not only holds. Pass = zero errors/warnings; read every `info` and either fix it or mark intentional off-canvas content with `data-layout-allow-overflow` (the camera world legitimately extends past the canvas).
5. **Render + artifact verification** — see below.

**Look at the pictures.** Automated checks passed a film whose scene chips were stacked at y=0 (missing `top` in CSS) — the contact sheet caught it in seconds. Always read the contact sheet at every iteration, and again from the *decoded MP4* at the end.

## 6. Rendering

```bash
node scripts/hf.mjs render revisions/<id>/composition \
  --quality delivery --fps 30 --workers 1 --output exports/<name>.mp4
```

- `--quality delivery` (requested) reports as `high`. Keep `--workers 1` on ~2 GB machines.
- Render temp goes to `.cache/hyperframes-tmp` via the wrapper — **not** `/tmp` (a ~1 GB tmpfs once aborted a render with a disk-full preflight error).
- 24 s landscape took ~72 s; 52 s portrait ~2.5 min. Add margin for audio muxing.
- Streaming encode engages automatically for single-worker MP4 renders.

## 7. Verify the artifact

```bash
FFPROBE=$(node -p "require('ffprobe-static').path")
"$FFPROBE" -v error -show_entries stream=codec_name,width,height,r_frame_rate,nb_frames,pix_fmt \
  -show_entries format=duration,size -of json exports/<name>.mp4
# expect: h264, yuv420p, exact fps/frames, duration ≈ config.duration

FFMPEG=$(node -p "require('ffmpeg-static')")
# contact sheet from the DECODED file (mid-times, not just endpoints):
"$FFMPEG" -v error -i exports/<name>.mp4 -vf "select='eq(n,24)+eq(n,168)+…',scale=270:480,tile=4x3" -frames:v 1 sheet.png
# narrated films: confirm audio exists and isn't silent:
"$FFMPEG" -i exports/<name>.mp4 -map 0:a -filter:a volumedetect -f null - 2>&1 | grep -E 'mean_volume|max_volume'
```

Present **only the MP4**, with a short summary in the user's language (Czech). Never present the studio, HTML or this repo's internals as the deliverable.

## 7b. Sticker artwork workflow

Films in the sticker style use a coherent die-cut set, not stroke icons. The locked prompt template, keying pipeline and budget rules live in `revisions/004/STICKER_STYLE.md`. Summary for agents:

1. Plan the whole set first — **max 10 new stickers per session** (owner's rule); reuse existing ones as mini icons before generating new art.
2. Generate with the exact template into `stickers-src/` (pure green #00FF00 background), key with `colorkey=0x00FF00:0.26:0.10,despill=type=green`, normalize to 640×640.
3. Verify transparency (alpha min === 0) and family coherence on the contact sheet; **delete `stickers-src/` before committing** and delete stickers of superseded revisions.
4. In films: one hero sticker per narration beat, pop on the beat, small pulses for emphasis; `drop-shadow` seats them on the dark board.

## 8. Storage hygiene checklist

Run **at session start, before generating anything** (owner's order), and again after each delivered film:

- [ ] `exports/` contains exactly one current MP4 (delete superseded videos — the owner asked for this explicitly).
- [ ] No `*.log`, no scratch HTML, no old studio bundles.
- [ ] `git status` clean of `node_modules/`, `.cache/`, `.hyperframes/` (see `.gitignore`).
- [ ] Current revision keeps: config, src, audio, motion json, qa jsons, contact sheet, keyframes. Old revisions may drop per-frame keyframes.
- [ ] `du -sh . --exclude=node_modules --exclude=.cache` sanity check.

## 9. Publishing to GitHub

The repo is public. Flow used: `git init -b main` in the project root → commit → create the repo with the user's token via `GH_TOKEN` env (never write the token to disk, config or docs) → push. The token owner must **revoke and rotate** it after use because it traveled through chat. If pushes hit storage limits, prune `exports/` and per-frame QA images first (they are the only multi-MB files).

## 10. Pitfall archive (all real, all fixed once)

| Symptom | Cause | Fix |
| --- | --- | --- |
| Render aborts: disk full | default temp on small `/tmp` tmpfs | `scripts/hf.mjs` uses `.cache/hyperframes-tmp` |
| `npm test` hangs at first seek | `page.evaluate` returned the paused GSAP timeline (thenable → awaited forever) | block-bodied evaluate, return nothing |
| Graph reveal visibly snaps mid-draw | GSAP pixel-rounds `strokeDashoffset` on normalized paths | `autoRound:false` on every normalized draw |
| 1 px dot before the curve starts | zero-length dashed subpath with round linecap | cap style `butt` + no zero-length dashes; lead dot is a separate motion-path element |
| Handoff jump between swapped elements | authored coordinates off by 1 px + round linecap radius | align centers exactly; assert <0.2 px across the switch |
| Audio silent in render | `<audio>` without `id` | builder always emits `id="narration-N"` |
| Runtime warning, audio truncated | slot `data-duration` > real media length | config carries the runtime-measured length |
| Scene chips stacked at top (y=0) | missing `top` in CSS for absolutely positioned chips | explicit `top` per chip; caught via contact sheet |
| Stale titles/lines during scene swap | retire group didn't include headings/connectors | add every stale element to the retiring group |
| Icons silently replaced by fallback | revision `icons.mjs` imported a non-existent named export | import the default; builder warns loudly on icon-module failure |
| Lint: transform conflict errors | CSS `transform` + GSAP `y`/`scale` tweens | `fromTo` owns the transform; CSS keeps only opacity |
| Lint: initial-hide warnings | hidden states authored as timeline `set(…,0)` | hidden state lives in CSS; geometry via immediate `gsap.set` |
| `check` info flood: off-canvas panels | camera world extends past canvas by design | `data-layout-allow-overflow` on world sections |
| `--quality looks` normalized | Hyperframes maps it to `standard` | use `delivery` for final renders |
| Lint: `duplicate_media_discovery_risk` | the same image file used in several `<img>` elements | repeat small images as CSS `background-image` on an `<i>`/`<span>` instead |
| Runtime `clip_media_fit` on many clips | `ffprobe` reports MP3 encoder padding (~60 ms) on top of real audio length | adopt the check's measured length into `film.config.json` and re-run |
| Motion error `motion_appears_late` | entrance with slow opacity ramp (e.g. `power2.in` over 1.1 s) crosses the visibility threshold after the asserted time | split fast opacity from slow movement; assert against the opacity tween |
| Lint `gsap_repeated_fromto_without_baseline` | two `fromTo` tweens on the same target | baseline once with an immediate `gsap.set` outside the timeline, then use absolute `.to` tweens |
| Relative tweens (`y:'-=16'`, yoyo/repeat) | resolution depends on playback history | always author absolute target values (write out the yoyo legs) |
| Elements invisible although their container was animated | inner element also declared `opacity:0` in CSS and was never tweened itself | animate the element that carries the CSS hidden state, or override it (`opacity:1`) in CSS when the parent handles the entrance |
| CSS-background elements (`<i>`, `<span>`) render 0×0 | background-image needs explicit `width`/`height` — no `width` attribute fallback like `<img>` | set the size in CSS whenever a semantic element carries a background image |
| Forward seek leaves the camera in the previous viewport | zero-duration `TL.set(...)` swaps are not reliably triggered by forward seeks | swap with a 1 ms tween that carries `onUpdate` (e.g. a camera jump hidden under a dip) |
| Backward seek drifts ~0.001 on one element | rotation authored in CSS *and* tweened by GSAP (double transform ownership) | GSAP owns all transforms; CSS never declares `transform` on tweened elements |
| Contact-sheet tiles seem shifted/wrong | renderer-side contact sheets can drop/duplicate frames at fast pans | always verify suspicious frames by seeking them exactly and screenshotting individually |
